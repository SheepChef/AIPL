**学术创新保护许可证**

---

在源代码公开的软件项目遭到严重抄袭和滥用，大量作者的权益遭受侵犯的背景下，本《学术创新保护许可证》（AIPL）旨在遏制受保护作品遭到不正当使用，同时保障正常用户、作者和协作者依法享有的权利。

本许可证授予被授权人有条件的、非独占的非商业使用权，严格保障著作权人的学术优先权与成果控制权，限制未经许可的竞争性学术利用、商业利用及专利主张行为。

针对学术利用，本许可证仅限制被授权人依赖本作品获取学术声誉、学术资格或其他竞争性学术利益。私下研究、教学以及不依赖本作品获取学术利益的合理讨论不受本许可证额外限制。

针对商业利用，本许可证限制被授权人依赖本作品获取直接或间接经济利益、参加商业竞赛、获取第三方投资等。针对符合第 4.2 条的媒体和艺术作品，被授权人享有创作、发布和盈利自由。

本许可证为独立的源代码可获取授权框架，与部分主流开源许可证体系（包括 GPL）不兼容。本许可证中“源代码公开”系指作品源代码可以由公众获取、阅读和审查。日常语境下亦可简称“开源”，但该表述不表示本许可证完全符合 Open Source Initiative 的 《The Open Source Definition》。
